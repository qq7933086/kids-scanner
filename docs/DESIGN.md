# DESIGN —「健康小卫士扫描仪」设计规范

> Stage 1 产出（任务来源：`docs/PLAN.md` Stage 1）。本文是**配色/风格 token、部位×结局文案、父母面板交互**的唯一依据，后续所有界面、贴图、文案从这里取值。
>
> 维护约定：改文案只动词表不动结构；改 token 必须同步全部 SVG（贴图内写的是 hex 字面量，经 `<img>`/Canvas 光栅化时**吃不到**页面 CSS 变量，token 表是唯一真源）。

---

## 1. 一句话风格

**扁平圆润卡通（flat & round）**：粗墨线 + 大色块 + 胶囊形状 + 萌系脸谱。无渐变、无投影、无滤镜。所有"虫虫/细菌"都微笑——发现版是"温和的惊讶"，不是惊吓。

**三色语义**：绿 = 干净/表扬；橙 = 发现/提醒；蓝 = 扫描/中性操作。
**UI 图标**一律主色蓝填充 + 墨线描边。唯二例外：`sound-off.svg` 的斜杠用 `--orange`（状态警示）；`scan-frame.svg` 用"白衬底 + 蓝"保证压在视频画面上可见。

## 3. 贴图（SVG）风格规则

1. **画布**：一律 `viewBox="0 0 120 120"`，主体居中，四周留白 ≥ 10。
2. **描边**：`--ink`，宽 `6`，`stroke-linecap="round"`、`stroke-linejoin="round"`。唯一例外 `scan-frame.svg`：白色 `10` 衬底 + 主色蓝 `6`。
3. **形状**：扁平色块填充；矩形必圆角（胶囊优先）；体积感只用同色系深一号平涂（如 `--orange`→`--orange-deep`）。
4. **脸谱（统一萌系）**：实心墨点眼（r≈3–4，各带 1 个约 1px 白高光）+ 圆头弧线微笑（宽 6）+ `--blush` 椭圆腮红。生物一律微笑，禁止獠牙/眼泪/凶相。
5. **干净记号**：所有 `clean-*.svg` 右上角统一"绿底白勾圆徽章"（r=12–13，`--green` 底 + `--white` 勾 + 墨线圈），可轻搭在主体边角上。
6. **特效粒子**：`sparkle.svg` 无脸（小粒子，大量撒落用）；`star.svg` 是主角级星星，带脸。
7. **取色**：只允许第 2 节 token 的字面量 hex；新增颜色必须先进 token 表再使用。

## 4. 部位 × 结局 文案词表

**语气规则**：短句、叠词、行动具体。不说"脏死了/会生病"吓唬孩子；发现版 = 温和惊讶 + 一个立刻能做的具体动作；干净版 = 具体表扬 + 保持习惯。每张结果卡：主文案（大字）+ 副文案（行动/表扬）+ 小妙招（点按钮展开的 2–3 条短句）。

## 5. 父母面板（结果控制）交互

**定位**：教育工具入口，低调但不加密（v1 不设密码；防孩子误触靠"长按 1.5s"与低视觉权重）。

- **入口**（都在扫描界面，两个都实现）：
  1. 右下角小齿轮（`gear.svg`，约 36px、70% 不透明度，视觉权重低于扫描主体）；
  2. 扫描画面**长按 1.5s**（不抬起、不移动）。
- **打开**：底部抽屉小卡片（`--paper` 底、圆角 20、`--ink` 细边、轻上滑入场）。打开时**扫描计时暂停、画面定格**，关闭后继续——不打断孩子的仪式感，爸妈也有充足时间选。
- **内容**：标题「爸妈小面板」+ 三个单选大按钮：
  - 「这次发现」（`--orange` 圆点）→ 下一次结果锁定为发现；
  - 「这次干净」（`--green` 圆点）→ 下一次锁定为干净；
  - 「随机」（`--primary` 圆点，默认）→ 干净 ~65% / 发现 ~35%；
  - 说明小字：「只影响下一次扫描，之后自动回到随机」。
- **生效与回落**：选择即时生效并轻提示（如「下次扫描：发现小虫」）；只影响下一次扫描，扫描结束自动回到随机；**不写 localStorage**，刷新即清。
- **关闭**：点遮罩空白处或「收起」按钮。
